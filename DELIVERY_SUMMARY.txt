## 🚀 Get Started in 3 Steps

### Step 1️⃣: Build
```bash
cd c:\UI-Automation-JavaSelenium-Framework-
mvn clean install
```
**Time:** 2-3 minutes (first run includes dependency download)

### Step 2️⃣: Configure
Edit `src/main/resources/config.properties`:
```properties
app.url=https://your-app-domain.com
```
**Time:** 1 minute

### Step 3️⃣: Run Tests
```bash
mvn test
```
**Time:** Depends on app (usually 5-10 minutes for all 17 tests)

## 🎯 Feature Highlights

### ✨ Page Object Model (POM)
```java
// Clean, readable test code
LoginPage loginPage = new LoginPage(driver);
loginPage.login("9876543210", "password123");
AssertUtils.assertUrlContains(driver, "dashboard");
```

### 🔐 Secure Credentials
```java
// Encrypted test data
Map<String, String> userData = TestDataReader.getUser("validUser");
// Returns: {"mobile": "9876543210", "password": "decrypted"}
// Actual stored value is encrypted in users.json
```

### 📱 OTP Handling
```java
// Automatic OTP capture from network response
OTPInterceptor interceptor = new OTPInterceptor(driver);
interceptor.startListening();
// ... user requests OTP ...
String otp = interceptor.getCapturedOtp(); // Captured automatically
```

### 📤 File Upload
```java
// Simple file upload
UploadDocumentPage page = new UploadDocumentPage(driver);
page.uploadFile("sample.pdf");
page.verifyUploadSuccess();
```

### ✅ Assertions
```java
// 8 different assertion methods
AssertUtils.assertVisible(driver, locator);
AssertUtils.assertClickable(driver, locator);
AssertUtils.assertTextEquals(driver, locator, "Expected Text");
AssertUtils.assertUrlContains(driver, "dashboard");
```

## 🚀 Quick Commands Reference

```bash
# Build the project

# Run specific test class

# View test reports
# Open: target/surefire-reports/index.html
```

## 💡 Pro Tips

**💡 Tip 1:** Use ConfigConstants for all magic values
```java
// Instead of hardcoding
// Use: ConfigConstants.LOGIN_PAGE_URL
```

**💡 Tip 2:** Reuse AssertUtils methods
```java
// Don't write custom assertions
// Use: AssertUtils.assertVisible(driver, locator)
```

**💡 Tip 3:** Leverage TestDataReader for tests
```java
// Don't hardcode test data
// Use: TestDataReader.getUser("validUser")
```

**💡 Tip 4:** Keep locators updated
```java
// When element IDs change, update only Locators class
// No need to change test code
```

**💡 Tip 5:** Use meaningful test names
```java
// Good: testValidLoginWithCredentials()
// Bad: test1()
```
